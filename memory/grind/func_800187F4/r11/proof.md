## 3. Mechanism and necessity, per Ruling 11 local

Seat decisions cited: global.c:635-656 `allocno_compare` (priority = floor_log2(n_refs) * n_refs /
live_length * 10000; allocnos seated in that order, find_reg taking the lowest free register);
local-alloc.c:472 (a pseudo living in one basic block with one death is a local quantity, seated
before global allocation); local-alloc.c combine_regs (:1784, called :1295-1346: a local quantity
tied to a dying input register).

### idx — global.c allocno priority
- Reuse (dumps c6): pseudo 89, nrefs 45, livelen 245, pri **9183**, ord 38 -> **$t2**, after bits
  ($a0, 21000), vx/vy/vz, the node+8 giv and `nforce` (pseudo 90, 10000, $t1), all live across the
  force loops. Target: `addiu $t2,$t2,1; slt $v0,$t2,$t1` closing each force loop and
  `addiu $t2,$t2,1; slt $v0,$t2,$v0` closing the ellipsoid loop.
- Per-value (r11pv_idx): the add / subtract counters (16 refs, livelen 25 / 22, pri 25600 / 29090,
  ord 23 / 21) are seated before bits and take **$a0**; 67 lines.
- Necessity: a force-loop counter's value lives only in its loop (its writes are the loop's init and
  increment, its reads the test, `idx == 3` and the increment; the next write is the next loop's
  init). In any spelling giving each loop its own variable, its n_refs (16) and live length (the
  loop, 22-25 insns) are fixed by the statement list, whatever the declaration order, scope, name or
  32-bit type, so its priority is >= 25600 > 10000 and it is seated first. Dropping below 10000
  needs a live range beyond ~64 insns, i.e. carrying another loop's value: two force loops shared
  still give 34042 (ledger [s2] 4); only all three (the ellipsoid loop is ~198 insns) give 9183.
  No FAKE family closes it (§5).

### nforce — the floor_log2 step

- Necessity: a single count's refs are its load and the loop test (7), live over its loop (21), in
  every per-value spelling; floor_log2(7) = 2 gives 6666 < 9183. Only one allocno holding both counts
  reaches floor_log2(14) = 3. No FAKE family closes it (§5).

## 4. The two FAKE dead stores (dead-store-fake-exception)

`sq1 = 0;` (just before `tot = dist1 + dist2;`) and `depth = 0;` (after the ellipsoid loop), each
annotated `/* FAKE: dead store; mechanism: ... */` on the statement.
- **Mechanism (named, prerequisite 2)**: reg_scan_mark_refs records every REG reference, SET
  destinations included, as the register's last reference (regclass.c:1763-1764, `regno_last_uid`),
  before cse runs. cse.c make_regs_eqv (:840-857) makes a newly equivalent register the class head only
  if its last reference is later than the current head's. With the dead store:
  - `sq1`'s last reference is after `temp`'s last use (the focus-1 table byte), so for `temp = sq1`
    `sq1` stays the head: the compare and both table indexes read `sq1` ($a1) and the copy stays its
    own move (the target's `addu $a0,$a1,$zero`). Without it `temp` becomes the head, cse rewrites
    sq1's reads to `temp`, the sum lands in `temp`'s register and the copy disappears: 26 lines.
  - `depth`'s last reference is after the ellipsoid loop, later than the `depth / 8` expansion's copy
    (`t = depth; if (t < 0) t += 7; t >>= 3`), so `depth` stays the head: the sign test reads `depth`
    (target `bgez $v1`, the copy in the delay slot). Without it the copy becomes the head (dump
    insns 645-649 read `(reg 276)`): `bgez $v0`, 4 lines.
  flow's life analysis deletes both stores afterwards: no instruction is emitted (644/644).
- **Lever exhaustion (prerequisite 1)**: the FAKE-free forms measured: the per-value spellings without
  the store (26 / 4; both 30); structural respellings (work: `temp = sq1 = ...` chained 26, function
  scope 26; delta: depth written inline three times 4, function scope 4; v1 ledger r11/measurements.md
  rows st_work_* / st_delta_*); self-assign after the loop 4, chain-extenders 117 / 6 (delta), 146
  (work); two permuter campaigns from the split bodies (§6). The only FAKE-free byte-exact form, a
  variable carrying a second value (the v1 reuse), is inadmissible: the dead-store spelling defeats its
  Ruling 11 (D)(3) necessity (layer-2 FAIL, rejected/r11-work-delta-reuse-layer2-fail-0.md).
- **Annotation (prerequisite 3)**: on each statement, naming the mechanism and this file.
- Stores are to locals whose stored value is never read (store-level deadness, Ruling 2).
