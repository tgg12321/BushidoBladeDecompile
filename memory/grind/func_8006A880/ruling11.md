variable holds value 2 (the +0x40 table), a different object. Value 5 re-reads the same

distinct object, and external calls are not provably distinct, so by C semantics the slot
(and root) may have changed and the variable is not proven to hold the value already. The
compiler reloads both `lw v1,4(s0)` and `lw s2,0x24(v1)` for exactly that reason; a body

## (D)(2) Mechanism
- `sheets`: the target loads values 2, 4 and 5 straight into $s2 (0x8006AB8C, 0x8006AF24,
  0x8006AFC0) and reads each before any call or label. Only a pseudo that global.c
  allocates can sit in a callee-saved register there, and global.c only sees pseudos that
  local-alloc did not take. local-alloc.c `block_alloc` (:1123) takes every pseudo used in
  a single basic block; its `find_free_reg` (:2135, register scan :2251-2275, no
  REG_ALLOC_ORDER on MIPS) returns the LOWEST-numbered register not live over the
  quantity's life and not fixed. For a quantity that crosses no call, `used` starts from
  `fixed_reg_set` (:2167), so a free call-used register ($v0..$t7, 2-15) is always found
  before $s2 (18). In the reuse spelling the variable crosses 11 calls and lives in several
  blocks (`dies in 5 places`), so it is global-allocated and seated in $s2 with the loop's
  table value (the target's register).
  Value 3 (row-7 table) crosses calls on its own, so it is global even when split; global.c
  `find_reg` (:952) pass 0 takes the lowest register in regs_used_so_far minus conflicts
  minus regs_someone_prefers (:998-1001). The main-loop counter's $s1 is used so far and
  dead after the loop, so the split value takes $s1 (trace above), never $s2.
- `row_mask`: the target keeps D_8009BC08 (0x8006A8C0..0x8006A980) and D_8009BC04
  (0x8006A9E4..0x8006AD78) in $s6, while $s4 (0x30 constant, set 0x8006A998) and $s5 (the
  sheet giv, set 0x8006A9B8) are born after the BC08 value's last read. In the reuse
  spelling the one pseudo also spans the BC04 range, so it conflicts with the $s4/$s5
  pseudos and global.c seats it in $s6 (tag `cand`, ord=11 pseudo=76 hardreg=22).

## (D)(3) Necessity (every one-variable-per-value spelling)
- `sheets`, property: values 2, 4, 5 share a pseudo that is live across calls and in more
  than one basic block. In any per-value spelling each of these values has its own
  variable whose every write and read lie between the target's load and its single use,
  one basic block with no call (the target's instruction stream fixes that range; a C
  local is live exactly from its write to its last read). local-alloc therefore allocates
  it, and find_free_reg returns a call-used register (<= 15) before $s2 — whatever the
  declaration order, scope, type or statement order, because none of those changes that
  the quantity is single-block and call-free. So no per-value spelling reproduces
  `lw s2,0x40(v0)` / `lw s2,0x24(v1)` (x2). Value 3 independently: split, it is a global
  pseudo whose range starts after the main loop; the main-loop counter (s1) is dead there
  and, having many refs in a loop (priority >= 1000 in every measured spelling vs <= 300
  for a 2-ref value live >= 70 insns), is allocated first, so pass 0 hands the value $s1.
- `row_mask`, property: the BC08 value is in a pseudo that is live while the $s4/$s5
  pseudos are. Split, the BC08 pseudo's range ends at 0x8006A980, before $s4/$s5 are set,
  so it conflicts with neither. In any spelling that matches the rest of the target,
  whenever $s6 is in regs_used_so_far, $s4 is too: the first allocno to take $s6 got it
  in pass 1 (lowest non-conflicting) only because $s4 and $s5 were already held by
  conflicting allocnos. Pass 0 for the split BC08 pseudo then takes $s4 or lower unless
  $s4 is in regs_someone_prefers — which only carries hard-register preferences from
  copies with hard registers or local-allocated pseudos; no C statement copies to a
  callee-saved register, and $s4 in the target holds only the 0x30 constant, used in
  several blocks (global). Pass 1 likewise yields the lowest non-conflicting register
  (<= $s4). So the split BC08 value is never seated in $s6 (measured: $s2).
