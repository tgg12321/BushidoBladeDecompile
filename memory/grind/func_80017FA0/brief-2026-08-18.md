## 2. The refused-then-sanctioned spelling

The refused declaration, verbatim from `memory/grind/func_80017FA0/rejected/fully-dead-pad-oversized-locals.c:31`:

```c
void func_80017FA0(s32 *a0) {
    s32 pad[2];               /* FAKE fully-dead pad — FORBIDDEN, see above */
    volatile s32 *scr = (volatile s32 *)0x1F800000;
```

Properties of the refused spelling:

- **NOT volatile** — plain `s32 pad[2]`. The new family sanctions a **`volatile`** pad
  only (`engine/volatile_cheats.py:_is_sanctioned_pad` hard-requires the `volatile` token
  in the declaration line). The refused spelling therefore has to be **re-spelled**, not
  merely re-approved.
- **Type/size:** `s32[2]` = 8 bytes, matching the target's `.frame` of 8 bytes exactly.
  ALIGN8 makes 1–8 bytes a range (rejected file header: *"shape `s32 pad[2]`/`pad[1]`;
  ALIGN8 makes 1-8 bytes recoverable only as a range"*), so `volatile u32 pad[2]` is the
  in-family spelling.
- **Decl position:** FIRST declarator in the body — a **leading** pad, the same position as
  the SOTN exhibit and as the already-granted `func_8001E404`/`func_8003CF84` `pre_pad`.
- **Genuinely unused:** never written, never read, never address-taken. This is the
  unused-volatile-pad the ruling sanctions, *not* a barrier local.

**CRITICAL distinction — what is on main today is a BARRIER, not a pad.** The on-main carrier
(`src/code6cac.c:174` + `:224`) is:

```c
void func_80017FA0(s32 *a0) {
    s32 _frame;
    ...
end:
    asm volatile("" : : "m"(_frame));
}
```

`_frame` is non-volatile and is **referenced** — by an `asm volatile` memory-operand barrier
that forces `assign_stack_local` to keep the slot. The new family does **not** sanction this;
`__asm__` scheduling/allocation barriers remain a cheat under
`.claude/rules/inline-asm-injection.md` and the WIP notes classify it as such
(`memory/wip/func_80017FA0/notes.md`: *"HEAD forces it with `s32 _frame; asm volatile("" :: "m"(_frame))` — a dead-var + barrier, forbidden by the expanded catalog"*).
A second barrier sits at `src/code6cac.c:184`:

```c
        s32 val = ptr[0] << 7;
        asm volatile("" : "=r"(val) : "0"(val));
        *(volatile s32 *)0x1F8000B8 = val;
```

`val` is written and read — a register-coercion barrier, also **not** covered by the pad
family. Both barriers must be **deleted**, not converted.
