retirable WITHOUT the function reaching distance 0** — you only have to stop the label drift.

them. The failure mode is loud, though: a broken `insert_before` leaves the `.LsaTan5TakeAnim2_epilogue`
reference undefined and the link fails, rather than silently duplicating bytes.
