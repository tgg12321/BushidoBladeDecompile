Closing deliverable of Campaign 5, after the `text1a` adoption landed (`6e11d4da`, `cddd4bd1`).
Snapshot `~/bb2_cen/snap` from HEAD `f3ec41f3`, verified == oracle before measuring. Scripts:
`tmp/csz/census*.py`; instrument `tools/objdiff.py`. Raw data `~/bb2_cen/{screen,pass2,pass3}.json`.

## Method

1. **Static screen** for the two hazards measured on `text1a`: (a) a **≤8-byte extern declared
   as a scalar, living outside GPREL16 range of `$gp`, with its address taken** — at `-G8` cc1
   thinks it is 1-insn addressable and stops CSE-ing the base, but maspsx cannot rewrite it, so
   we pay a `lui` per use; (b) a **file-scope `__asm__` block**, which floats to the top of
   `.text` because `-G8` defers function bodies.
2. **Build pass** on candidates: `make GP_FILES=<stem> build/src/<stem>.o`, compared to the
   oracle object with the normalized method. Changed functions split into **regress** (carries
   no rules today, so it is byte-perfect from pure C and any change must be re-matched — what
   the two `text1a` siblings were) and **payoff?** (carries rules, so a change is a candidate
   improvement).
3. **Payoff verification**: honest pure-C distance measured with the engine sandbox at `-G0`
   and `-G8` for every payoff candidate. "Closer" is measured, never inferred.

**Screen calibration.** Post-adoption `text1a` screens at **1 offender, asm=N** (it needed 3
honest-type fixes + 1 extraction, all now done; the 1 residual is harmless — the file builds to
oracle). So **offender count is an upper bound on fix cost, not a hard block**: `BLOCKED` reads
as "needs N honest-type fixes first". 12 of 30 files screened PASS but all are trivial
(0–4 functions, ≤1 rule-carrying); the substantive files all carry offenders.

## Recommendations

- **`code6cac_c_mid` is the best next adoption**: the strongest single win in the tree
  (`func_80038170` 32 → 14), both candidates closer, only 3 regressions to re-match, 5 externs
  to retype, and **no file-scope asm to extract**. Smallest cost of any file with real payoff.
- **`main` is second**: two solid wins (−11, −12, both on long-standing banked endgames) but
  7 regressions, 25 flagged externs and an asm extraction. Worth it only if those two functions
  are wanted specifically — `tslGlobalMemFree_800861BC` is a banked endgame whose residual was
  re-scoped to prologue-emission order, so a −11 there is meaningful.
- **`code6cac_b` is the volume play but mixed**: the largest rule pool of any measured file (39)
  and 8 candidates, but the sample splits 2 closer / 2 same / 2 farther. Measure the remaining
  2 candidates before deciding.
- **`code6cac` is poor value**: 9 regressions to buy 1 win.
- **Do NOT adopt `system`** (its only candidate, `marionation_Exec`, gets *farther*), nor
  `text1a_c` / `code6cac_c2` / `ings` (zero payoff, pure cost).

## `text1b` — the biggest prize, and it does not build

96 rule-carrying functions across 485 — by far the largest pool — but
`make GP_FILES=text1b` **fails to assemble**: `src/text1b.c:14: Warning: missing .end`, then
`used $at without ".set noat"`. That is hazard (b) biting hard: the file-scope `__asm__` block
floats out of position and desynchronises the `.set`/`.ent` state. It must be extracted to
`asm/funcs/` + a C stub + an `asmfix` `replace_with_asmfile` entry (the `save_vc_ctrl` recipe in
[[decBs0]]'s notes) before any payoff can even be measured. With 73 flagged externs it is also
the most expensive screen in the tree. **Highest ceiling, highest cost, currently unmeasured.**

## Standing caveats

- The screen is deliberately conservative (see calibration): it flags symbols whose address is
  taken anywhere in the file, not only those cc1 actually CSEs. Treat offender lists as a
  worklist to triage, not a count of required edits.
- Every adoption is a **per-file owner-approvable follow-up**, and each needs the full five-step
  recipe from [[decBs0]]'s notes — `MASPSX_FLAGS_GP` parity is already on main, so per file it
  is: `GP_FILES` entry → retype offenders → extract file-scope asm → re-match regressions →
  full-build SHA1.
