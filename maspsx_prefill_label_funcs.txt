# with the instruction at its target label and pointed THAT branch one word past it;

# deletes the pre-instruction label and retargets the unfilled branches too. For the
# functions below, maspsx re-emits the label before that instruction and points the
# unfilled branches at it. One name per line; `#` comments. Net additions require the
# commit tag [infra-rule: maspsx-prefill-label] plus target-site evidence. Never
# globalize (36 target sites in 33 matched functions legitimately sit past the
# instruction).
