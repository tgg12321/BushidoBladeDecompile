FINDINGS
LIBAPI/SENDPAD is absent from 3.3, 3.5 and 3.6 LIBAPI.LIB; present in 4.0.
Its 4.0 .text is 48 words and has zero non-relocation-bit differences at
BB2 0x80079000. No equivalent .text+relocation+export module was found in
any other primary library in the three earlier versions.
175 distinct verbatim candidates have retained rows in rename_manifest.csv.
Of these, same-library/name exact .text+relocations+exports occur in:
3.3: 56; 3.5: 81; 3.6: 96; 4.0: 175.
79 of those 175 have no exact .text+relocation+export equivalent in
any primary library of 3.3/3.5/3.6 (see list below).
Inference: BB2 library provenance cannot be described as uniformly the
archived PsyQ 3.5 libraries. This supports a 4.0-era library input; it does
not identify the compiler/tool executable version, the SDK installed on the
original developer machine, or exclude modules shared with later releases.
AGENTS.md and every other existing doc remain unchanged.

SCOPE AND METHOD
All 193 status=verbatim entries from docs/naming/libscan/matches.json are
reported, including rejected/ambiguous scan candidates. Only retained
manifest module/address tuples are marked retained. A retained candidate
is not necessarily uniquely version-identifying; identical stubs and
alternate-library duplicates remain explicitly visible.
All SDK archive members in the primary PSX/LIB directories were parsed with
unchanged tools/libscan/psyq_lib.py: no container or OBJ parse errors.
4.0 reference lengths equal the recorded word counts for all 193 candidates;
all their recorded addresses were independently rechecked against the EXE
with zero masked differences. No manifest or scan was regenerated.
ID = raw .text byte-for-byte equal to 4.0, same .text relocation tuples
(type, offset, expression with section IDs normalized to section names),
and same .text exported names/offsets. This is stronger than a masked match.
ID/OBJ additionally means the full LNK archive-member bytes equal 4.0.
TEXT, REL, XDEF mark individual equal components when the ID gate fails.
diff=addr:N counts differing words against BB2 at the recorded 4.0 address
using that version member's relocations: 82/84 mask imm16, 74 masks low26,
16 masks the whole word. All encountered .text reloc types were supported;
no unknown type was silently masked. diff=0 alone is NOT raw byte identity.
size=Nw means the earlier member has a different .text length; no truncated
or padded comparison is counted as identical. absent means that archive
contains no member with this library/name. Search also finds alternate
library/member names with exact .text, relocation and XDEF equality.
Only .text is compared to the EXE; .data/.rodata/.bss are not independently
placed by the original text scanner. Whole-OBJ equality is a separate test.
The five status=near entries and near_manifest.csv evidence identify partial
or modified modules rather than whole-module byte identity and are not in
the exact-module table. Their current docs/rulings remain in force.
