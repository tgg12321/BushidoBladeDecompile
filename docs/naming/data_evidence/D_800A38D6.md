# D_800A38D6 -- naming evidence

- Address: `0x800A38D6`
- Current name: `g_gpu_ot_offset_update_count` (was `g_replay_pos_change_count`)
- Confidence: **medium**

## Storage / access pattern

.bss u16. Incremented in exactly two places, each beside the store of
`g_gpu_ot_offset_ptr`; never read.

## Usage in src/

- src/main/368E4.c -- `gpu_ResetDrawQueueAndPrepareViewAndLighting`:
  `g_gpu_ot_offset_base_ptr = g_gpu_ot_ptr; g_gpu_ot_offset_update_count++;
  g_gpu_ot_offset_ptr = g_gpu_ot_ptr + 4;`
- src/main/4510C.c -- the matching reset in
  `motion_ResetDrawQueueAdvanceCounterSetOtUpdatePlaybackAndFlush`, same three
  statements.

## Why this name

It counts updates of the offset ordering-table pointer
`g_gpu_ot_offset_ptr` (once per store, in both resets). The earlier
replay-position reading was dropped: the old `stage_InitCollision` read no
longer exists, and the counter has no reader at all.
