Surviving: 16 member rows (pairs.txt). Pool (Unk8006E49CRec) and draw-context cursor

plus Unk8006919CRec: unk_18=row_sheets, unk_40=cursor_row_sheets, unk_44=rect_rows,
unk_48=sheet_pair_box_sizes.

Why shared names (differs from Codex's *_buffer / *_cursor split): naming_member_apply.py cannot
rename same-spelled members of two types when a source line holds both
(`s.unk_04.unk_08 = p->unk_08;` 5ED34.c:243-250, 64FD8.c:1249-1256, 1625-1631, 1724-1730): with
distinct names the dry run exits 1 with 19 UNRESOLVED lines. The code shows the pair alike (the
cursor is the pool member copied verbatim, then advanced), so "prims" names the prim storage
without claiming base vs cursor lifetime. Reviewer may prefer the Codex split
(textured_quad_buffer/_cursor, ... tile_buffer / sprite_buffer, tile_cursor / sprite_cursor); that
needs a hand edit of those 19 lines (tool reports exit 1) -- not done here.
