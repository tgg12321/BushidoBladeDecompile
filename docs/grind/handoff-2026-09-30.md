## Lessons for the next orchestrator

These are also in the harness memory `project/parallel-manual-orchestration-2026-09-26`.

- **Write rule text as ordered first-match procedures with explicit definitions.** Rule-doc reviews took 6-8 rounds
  each when the rows overlapped. For compiler-dump evidence, require `.greg` or the final `.s`: `.rtl` and `.cse` are
  produced before reload and can't prove the final addressing.
- **A changed body re-certifies its remaining casts** (the rev-21424 ruling). Disclosure suffices for single-handle
  byte-offset walks but not for overlapping handles. Run one systematic, per-hit scan before the first review, not
  after it.
- **Every path cited in a comment must exist.** Re-certified bodies often cite gitignored `tmp/` files, so restore or
  bank them first.
- **Lock behaviour.** The reintegration lock is per session, so lanes share it. The landing lock is the real
  serializer. Lanes waiting on it in the background never wake, so message them directly.
