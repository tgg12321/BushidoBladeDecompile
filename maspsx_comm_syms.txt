# Sony ASPSX 2.34 gives a COMMON symbol (a tentative definition `T sym;` in the file, `.comm`)
# gp addressing for its base `sym` only, never for `sym+N`; `static` and initialized objects get
# gp at every offset. Our C declares every such variable `extern`, so maspsx cannot tell them
# apart. Format `func: sym, sym` (the sdata_exclude.txt format): inside `func`, an operand
# `sym+N` (N != 0) of a listed symbol is assembled in maspsx's ordinary non-gp form. Nothing
# else changes (not the base access, no other symbol or function, no storage emitted). The gate
# only removes gp. Each row needs, in the landing function's ledger, the shipped signature
# (base gp + a direct lui/%lo sym+N in that function's original bytes) and Sony's ASPSX 2.34
# reproducing it from a tentative definition (extern / static / initialized / -G0 differing).
# Net additions require the commit tag [infra-rule: maspsx-comm] plus that evidence and a fresh
# layer-2. Never globalize (initialized/static objects are legitimately gp at an offset:
# g_anim_select+2/+4, D_800A34F0+2, D_800A3588+2 / D_800A358C+2).
